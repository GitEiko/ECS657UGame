## Controls

### Keyboard Controls:

-   **W** - Move forward
-   **S** - Move backward
-   **A** - Move left
-   **D** - Move right
-   **Mouse Movement** - Look around / change direction
-   **Left Shift** - Sprint
-   **C** - Stash item
-   **X** - Close panel
-   **Left Mouse** - Interact
-   **Right Mouse** - Throw Item
-   **Middle Mouse/Scroll** - Change between inventory items

### Controller Controls:
-   **Left Stick** - Move around
-   **Right Stick** - Look around
-   **Right Trigger** - Sprint
-   **Button East** - Throw
-   **Button South** - Interact
-   **Button North** - Stash item
-   **Button West** - Close panel
-   **Left-Right D-pad** - Change between inventory items

### Intended player experience
The player must navigate their way through the map visiting different rooms and completing number and word-based puzzles as they go. The player must avoid coming into contact with the enemy and can pick up and store items in the inventory that can be used to stun the enemy. Once every room has been traversed and the final passcode is found the player can escape the hospital and win. The player has five lives.

### Level features
The game is broken down into 36 rooms that act as the levels for this game. Each room has a different puzzle that the user needs to solve to get the passcode to the next room. The puzzles vary in difficulty.
